# CRUSH, BABY!

*Crush. Kiss. Ghost. Repeat.*

An immersive, cinematic love story in the browser (Three.js, WebGL, Web Audio): an elevator, a carousel behind red velvet curtains, a melting candle, a black swan pool, a corridor of light, a garden of mirrors — and back to the ringing elevator.

**Experience it** through GitHub Pages. Headphones recommended.
